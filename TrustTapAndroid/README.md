# TrustTap Android

This is the Android Studio project. Open this folder in Android Studio, not only the outer backend folder.

The app supports:

- Photo Picker for images and videos.
- Share Sheet receiving for images, videos, and `text/plain`, with automatic analysis when opened from Share.
- A large Plain text input for pasting or typing messages; text results are stored in History.
- Results include extracted text, suspicious-link details, safer next steps, and an Ask TrustTap follow-up panel.
- TalkBack-friendly labels and live-region updates, plus spoken results and replay.
- Local Room history with saved thumbnails and full result details.
- Settings/DataStore for changing the backend URL without editing source code.

TrustTap does not request SMS or storage permissions. For the full backend,
phone, emulator, firewall, Share Sheet troubleshooting, training, and TEE status
instructions, read the [main README](../README.md).
